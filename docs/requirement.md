# 要件定義：マイクロブログ（アプリ紹介ブログ）

## 概要

自分が開発したアプリを投稿形式で紹介する、個人向けの公開マイクロブログ。

---

## 技術スタック

| 項目 | 内容 |
|------|------|
| フレームワーク | Next.js 15（App Router） |
| 言語 | TypeScript |
| 記事管理 | MDXファイル（Gitリポジトリ内） |
| 画像ストレージ | Vercel Blob |
| デプロイ | Vercel |
| スタイリング | 未定（Tailwind CSS推奨） |

---

## 機能要件

### 記事（投稿）

- MDXファイルで記事を管理する（`/posts/*.mdx`）
- フロントマター（YAML）で以下のメタデータを管理する
  - タイトル
  - 投稿日
  - 説明文（サマリー）
  - タグ（複数可）
  - カバー画像URL（任意）
- Markdownの本文中に画像を埋め込める
- コードブロックのシンタックスハイライト対応

### 画像

- Vercel Blob に画像をアップロードして管理
- MDX内からURLで参照する

### ページ構成

| ページ | パス | 内容 |
|--------|------|------|
| トップ（一覧） | `/` | 投稿一覧（新しい順） |
| 記事詳細 | `/posts/[slug]` | MDX記事の表示 |
| タグ絞り込み | `/tags/[tag]` | タグ別の記事一覧 |

### 閲覧者向け機能

- 記事一覧の表示（新しい順）
- タグによる絞り込み
- **コメント・いいね・シェアボタンは不要**

---

## 非機能要件

- 管理画面なし（記事はローカルでMDXファイルを作成 → git push で公開）
- 認証不要
- SEO対応（OGP、メタタグ）
- レスポンシブデザイン（モバイル対応）

---

## 開発フロー（記事投稿の流れ）

1. ローカルで `/posts/app-name.mdx` を作成・編集
2. 必要な画像は Vercel Blob にアップロードしてURLを取得
3. MDXにURLを埋め込む
4. `git push` → Vercel が自動デプロイ → 公開
